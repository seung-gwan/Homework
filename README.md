# 사과나무 · 쉬운 디지털 생활 안내

기존 Apple Tree 프로젝트를 실제 홈페이지 사진에서 누를 위치를 알려주는 사이트로 개편했습니다. 원본 저장소의 안내 사진 30장을 복원했으며 사진 안내 13개와 기초 안내 8개, 총 21개 안내·64개 단계를 제공합니다.

## 주요 기능

현재 첫 화면은 **지역 선택 → 이용 항목 선택 → 사진 안내**로 진행하는 대화형 선택 화면입니다. 자유 대화를 생성하는 AI 서비스가 아니라 원본 사진과 연결된 선택지로 정확한 안내를 보여줍니다. 본문에는 사진과 짧은 명령문, 큰 이전·다음 사진 버튼, 큰 공식 사이트 버튼만 표시합니다. 카드 설명·사진 수·안내 배지·하단 설명문은 제거했습니다.

화면 오른쪽 아래에는 **화면 확대(100~200%)와 돋보기(150~400%)**가 함께 고정되어 있습니다. 화면 확대는 기존 줄바꿈을 유지하는 전체 캔버스 배율 방식이며, 확대 전 보던 중심 위치를 유지합니다. 두 기능을 동시에 사용할 수 있습니다. 기존의 사진별 확대 메뉴와 큰 사진 창은 화면 전체 확대 기능으로 통합했습니다.

- 스크롤해도 따라오는 화면 돋보기: 150~400% 확대, 본문 글자 크기·배치·스크롤 위치 유지
- 화면 전체 확대: 줄바꿈 유지, 보던 중심 위치 유지, 확대된 사진에서 마우스로 끌어 이동
- 실제 캡처 위의 번호·테두리로 누를 메뉴 위치 안내, 번호 선택 시 메뉴 이름 설명
- 큰 사진과 짧은 지시문, 큰 이전·다음 사진 버튼과 공식 사이트 버튼
- 지역과 이용 항목을 고르는 대화형 선택 화면, 키보드 탐색
- 별도의 안내 목록에서 지역·주제별 분류와 검색
- 17개 시·도와 기존 경기도 광주시 안내에 맞춘 지역 선택
- 기존 HTML 주소 33개 유지, 휴대폰 화면 대응

회원가입이나 실제 민원 신청을 받지 않습니다. 설정·지역·저장한 안내·학습 위치는 브라우저의 localStorage에만 저장합니다. 읽어주기는 브라우저/운영체제 음성 기능을 사용하며 기기별 지원이 다릅니다. 한국어 글꼴은 Google Fonts에서 불러오며, 불러오지 못하면 시스템 글꼴을 사용합니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

표시된 `http://127.0.0.1:4175`를 엽니다. 파일로 직접 `ex02/src/main/WebContent/index.html`을 열어도 기본 안내를 볼 수 있습니다. 음성·저장 등 브라우저 기능은 환경에 따라 제한될 수 있습니다.

```sh
npm run check
```

안내 데이터, 스크립트 구문, 기존 페이지와 로컬 자산 연결을 점검합니다. 소스 문서 루트는 `ex02/src/main/WebContent`입니다. `npm run build`는 같은 내용을 `dist`로 복사하며 Sites 배포에서 이 폴더를 사용합니다. JSP·DB·별도 서버 없이 정적 호스팅에서 이용할 수 있습니다.

## 콘텐츠 수정

- `guides.js`: 9개 안내, 단계, 지역, 공식 출처
- `photo-guides.js`: 원본 안내 사진과 지역별 설명, 버튼 표시 좌표
- `app.js`: 화면 구성, 검색, 저장, 단계별 안내, 읽어주기
- `view-tools.js`: 고정된 화면 확대·돋보기 도구와 화면 이동
- `simple.css`: 대화형 선택 화면, 간소화된 사진 안내와 큰 버튼
- `styles.css`: 반응형 디자인, 대비, 확대, 인쇄
- `assets/screens/`: 원본 저장소에서 복원한 실제 안내 사진 30장
- `assets/`: 사과나무 아이콘 등 정적 자산

## 안내 근거

- [신촌동 주민센터](https://www.sdm.go.kr/dong/sc/index.do): 주민센터·자치회관 메뉴 예시
