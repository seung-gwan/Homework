# 사과나무 · 쉬운 디지털 생활 안내

기존 Apple Tree 프로젝트를 어르신이 읽고 따라 하기 쉬운 웹사이트로 개편했습니다. 주민센터·민원, 복지, 건강, 배움·운동, 일자리, 인터넷 기초를 9개 안내와 35개 단계로 설명합니다.

## 주요 기능

- 글자와 화면을 100~200%로 확대·축소하고 설정 기억
- 화면 대비 조절, 현재 단계 읽어주기, 키보드 탐색
- 단계별 안내와 클릭·검색 연습, 전체 안내 인쇄
- 주제별 분류와 검색, 안내 저장, 학습 위치 기억
- 17개 시·도와 기존 경기도 광주시 안내에 맞춘 지역 선택
- 기존 HTML 주소 33개 유지, 휴대폰 화면 대응

회원가입이나 실제 민원 신청을 받지 않습니다. 설정·지역·저장한 안내·학습 위치는 브라우저의 localStorage에만 저장합니다. 읽어주기는 브라우저/운영체제 음성 기능을 사용하며 기기별 지원이 다릅니다. 한국어 글꼴은 Google Fonts에서 불러오며, 불러오지 못하면 시스템 글꼴을 사용합니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

표시된 `http://127.0.0.1:4175`를 엽니다. 파일로 직접 `ex02/src/main/WebContent/index.html`을 열어도 기본 안내를 볼 수 있습니다. 음성·저장 등 브라우저 기능은 환경에 따라 제한될 수 있습니다.

```sh
npm run check
```

안내 데이터, 스크립트 구문, 기존 페이지와 로컬 자산 연결을 점검합니다. 배포 시 정적 문서 루트는 `ex02/src/main/WebContent`입니다. JSP·DB·별도 서버 없이 정적 호스팅에서 이용할 수 있습니다.

## 콘텐츠 수정

- `guides.js`: 9개 안내, 단계, 지역, 공식 출처
- `app.js`: 화면 구성, 검색, 저장, 확대, 읽어주기
- `styles.css`: 반응형 디자인, 대비, 확대, 인쇄
- `assets/`: 직접 작성한 SVG 일러스트와 아이콘

## 안내 근거

2026년 11월 3일 정부24, 복지로, 신촌동 주민센터의 공식 안내와 메뉴를 참고했습니다. 화면·메뉴·신청 조건은 변경될 수 있습니다. 각 안내에 출처를 함께 표시합니다. 노인일자리여기는 접속 제한으로 최신 화면을 검증하지 못해 일반적인 공고 확인 방법으로 안내하고 이 제한을 명시했습니다.

- [정부24](https://www.gov.kr/): 민원 검색·인증·신청내역
- [주민등록표 등본(초본) 발급](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000015): 서류 발급 안내
- [정부/지자체 누리집](https://www.gov.kr/portal/orgSite): 공식 지역 홈페이지 찾기
- [복지로 서비스 소개](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/intro/intro/info/01/index.html): 복지 검색·신청
- [복지로 모의계산](https://www.bokjiro.go.kr/ssis-tbu/twatbz/mkclAsis/mkclPage.do): 모의계산의 참고용 한계
- [신촌동 주민센터](https://www.sdm.go.kr/dong/sc/index.do): 주민센터·자치회관 메뉴 예시
- [노인일자리여기](https://www.seniorro.or.kr:4431/seniorro/main/main.do): 기존 프로젝트의 공식 일자리 연결

기존 `Gwangju_*` 페이지는 광주광역시가 아니라 **경기도 광주시** 홈페이지를 가리켰으므로 두 지역을 구분했습니다.
