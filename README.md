# 사과나무 · 쉬운 디지털 생활 안내

기존 Apple Tree 프로젝트를 실제 홈페이지 사진에서 누를 위치를 알려주는 사이트로 개편했습니다. 원본 저장소의 사진 30장과 공식 사이트에서 확보한 사진 17장으로 사진 안내 19개와 기초 안내 2개, 총 21개 안내·60개 단계를 제공합니다.

## 주요 기능

첫 화면의 **지역찾기**는 지역 선택 → 이용 항목 선택 → 사진 안내로 진행합니다. 선택 후에도 질문과 선택지의 시작 위치를 유지합니다. 본문에는 사진과 짧은 명령문, 큰 이전·다음 사진 버튼, 큰 공식 사이트 버튼만 표시합니다. 입력 가능한 모의 신청·검색 화면은 제거했습니다. 안내 목록의 검색창은 실제 안내 검색에 사용합니다.

**화면 확대(100~200%)와 돋보기(150~400%)**가 함께 고정되어 있습니다. 컴퓨터에서는 버튼 높이 76px, 기호 글자 36px로 표시하며 넓은 화면에는 하단 한 줄로 배치합니다. 휴대폰은 작은 화면에 맞는 두 줄 도구를 사용합니다. 화면 확대는 기존 줄바꿈과 보던 중심 위치를 유지합니다. 두 기능을 동시에 사용할 수 있습니다.

- 스크롤해도 따라오는 화면 돋보기: 150~400% 확대, 본문 글자 크기·배치·스크롤 위치 유지
- 화면 전체 확대: 줄바꿈 유지, 보던 중심 위치 유지, 확대된 사진에서 마우스로 끌어 이동
- 실제 사진 위의 빨간 원으로 누를 메뉴 위치 안내. 사진과 표시에는 입력·신청 기능이 없습니다.
- 큰 사진과 짧은 지시문, 큰 이전·다음 사진 버튼과 공식 사이트 버튼
- 지역과 이용 항목을 고르는 선택 화면, 키보드 탐색
- 별도의 안내 목록에서 지역·주제별 분류와 검색
- 17개 시·도와 기존 경기도 광주시 안내에 맞춘 지역 선택
- 기존 HTML 주소 33개 유지, 휴대폰 화면 대응

회원가입이나 실제 민원 신청을 받지 않습니다. 확대 배율은 브라우저에 기억하지만 안내 진행 단계는 저장하지 않습니다. 목록으로 나간 뒤 다시 열거나 새로고침하면 첫 사진부터 시작합니다. 한국어 글꼴은 Google Fonts에서 불러오며, 불러오지 못하면 시스템 글꼴을 사용합니다.

## 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

표시된 `http://127.0.0.1:4175`를 엽니다. 파일로 직접 `ex02/src/main/WebContent/index.html`을 열어도 기본 안내를 볼 수 있습니다. 음성·저장 등 브라우저 기능은 환경에 따라 제한될 수 있습니다.

```sh
npm run check
```

안내 데이터, 스크립트 구문, 기존 페이지와 로컬 자산 연결을 점검합니다. 소스 문서 루트는 `ex02/src/main/WebContent`입니다. `npm run build`는 같은 내용을 `dist`로 복사하며 Sites 배포에서 이 폴더를 사용합니다. JSP·DB·별도 서버 없이 정적 호스팅에서 이용할 수 있습니다.

## 콘텐츠 수정

- `guides.js`: 9개 안내, 단계, 지역, 공식 출처
- `photo-guides.js`: 원본 안내 사진과 지역별 설명, 버튼 표시 좌표
- `app.js`: 화면 구성, 검색, 저장, 단계별 안내, 읽어주기
- `view-tools.js`: 고정된 화면 확대·돋보기 도구와 화면 이동
- `simple.css`: 대화형 선택 화면, 간소화된 사진 안내와 큰 버튼
- `styles.css`: 반응형 디자인, 대비, 확대, 인쇄
- `assets/screens/`: 원본 사진 30장과 공식 사이트 사진 17장
- `assets/`: 사과나무 아이콘 등 정적 자산
